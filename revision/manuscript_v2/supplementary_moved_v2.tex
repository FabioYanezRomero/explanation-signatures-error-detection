\section{SubgraphX: explanation and node ranking}

SubgraphX returns a set of nodes rather than a ranking. The explanation evaluated in every metric is the highest-scoring coalition within the node budget (20\% of the nodes) returned by the Monte Carlo tree search. The progression metrics of Dimensions~1 and~2 require an importance ranking over all nodes; for SubgraphX this ranking is the \emph{search credit} of each node, defined as the sum, over all coalitions explored by the search, of the coalition score divided by the coalition size. The nodes of the selected coalition are ranked first, and the remaining nodes follow in decreasing order of search credit.

\section{Text-to-graph conversion: parser models}
Hierarchical graphs are extracted with Stanza. POS tagging and dependency parsing use the \texttt{combined\_charlm} model, which incorporates character-level language model features; lemmatisation uses \texttt{combined\_nocharlm}; constituency parsing uses \texttt{ptb3-revised\_charlm}, trained on Penn Treebank 3 (revised), and produces Penn Treebank-style phrase structures. Dependency parsing yields head--dependent relations with morphological annotations (POS tags, lemmas, morphological features).
